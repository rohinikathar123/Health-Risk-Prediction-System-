# HealthWise AI – Health Risk Prediction System

## Project Overview
HealthWise AI is a machine learning project that demonstrates health risk category prediction using sample health-related data.

## Technologies Used
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Random Forest Classifier

## Features
- Sample health dataset analysis
- Data visualization
- Machine learning model training
- Model evaluation using a confusion matrix
- Interactive health risk prediction

## How to Run
1. Open the `.ipynb` notebook in Google Colab.
2. Run the cells in order.
3. Enter sample values to explore the prediction.

## Disclaimer
This project uses synthetic sample data for educational purposes only. Predictions are not medically validated and must not be used for medical diagnosis or treatment.
